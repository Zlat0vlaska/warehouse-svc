# warehouse-svc

![CI](https://github.com/Zlat0vlaska/warehouse-svc/actions/workflows/ci.yml/badge.svg)

Небольшой учебный сервис для управления складом товаров: HTTP API, PostgreSQL,
слои Handler/Service/Repository, Dependency Inversion через интерфейсы,
graceful shutdown, транзакции с FOR UPDATE для consistency, интеграционные
тесты через Testcontainers.
